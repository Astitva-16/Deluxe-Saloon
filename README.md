## 🚀 Run It

Clone the repo:

```bash
git clone https://github.com/YOUR-USERNAME/saloon-music.git
```

Open the project in VS Code and run:

```text
index.html
      ↓
Open with Live Server
      ↓
🎧
```

Or deploy it on Vercel and send the link to the boys.

---

## 💿 Add Your Own Songs

Put your songs inside:

```text
assets/
└── songs/
```

and covers inside:

```text
assets/
└── covers/
```

Then update the playlist in `script.js`.

The player handles the rest.
